# Contributing

Thanks for helping improve FrostShell!

1. Fork the repository and create a focused branch.
2. Keep the default experience lightweight and dependency-free.
3. Test PowerShell changes in a fresh PowerShell session.
4. Test Linux changes in both Bash and Zsh where possible.
5. Never add commands that require administrator/root privileges.
6. Include before/after screenshots for visual changes.

Please open an issue before large feature changes.
